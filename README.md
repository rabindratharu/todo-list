# todo-list
Advanced WordPress Plugin Development

# Setup
How to set up the plugin.

## Install Setup Packages.

- `composer install && npm install`

# Development

## Start Development Server.
- `npm run start`

## Start Production Server.
- `npm run build`


## Run PHPCS.

- `composer check-cs`
- `composer fix-cs`
- `npm run lint:css`
- `npm run lint:css:fix`
- `npm run lint:js`
- `npm run lint:js:fix`
